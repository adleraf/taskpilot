# 🚀 TaskPilot

TaskPilot is a modern and responsive task management web application built using **Flask**, **HTML**, **CSS**, and **SQLite**. It helps users stay organized by creating, managing, and tracking daily tasks with an intuitive dashboard and a clean user interface.

---

## ✨ Features

- 👤 User Authentication (Register & Login)
- ➕ Add new tasks
- ✅ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔍 Search tasks instantly
- 🎯 Set task priorities (High, Medium, Low)
- 📅 Add due dates
- 📊 Dashboard with:
  - Total Tasks
  - Completed Tasks
  - Pending Tasks
  - Progress Bar
- 📢 Flash notifications
- 📱 Fully responsive design
- 🎨 Modern glassmorphism UI

---

## 🛠️ Tech Stack

- **Backend:** Flask (Python)
- **Frontend:** HTML5, CSS3, Jinja2
- **Database:** SQLite
- **Authentication:** Flask-Login
- **Styling:** Custom CSS

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/TaskPilot.git
```

### 2. Navigate into the project

```bash
cd TaskPilot
```

### 3. Create a virtual environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
